# Seoul Bites - Restaurant Website

## About The Project
Seoul Bites is a restaurant website prototype developed as part of a web development module at Hämeenlinna University of Applied Sciences (HAMK).
The project showcases practical skills in both UI/UX design and full-stack web implementation.

## Built With
* **Design:** Figma
* **Frontend:** HTML5, CSS3
* **Backend:** PHP

## Team & Collaboration
This project was a collaborative group effort created by a team of three students. 
The workload, including UI planning, front-end development, and back-end scripting, was distributed evenly among all team members. 
Everyone contributed equally to both the design phase in Figma and the actual coding process, making it a truly joint achievement.

## Features
* Custom UI/UX design translated from Figma prototypes
* Responsive and visually appealing layout
* PHP integration for dynamic web elements
